# MenuMaker

A static Svelte 5 menu creation app built with runes, Tailwind CSS, and Flowbite Svelte.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

The GitHub Actions workflow in `.github/workflows/deploy.yml` publishes the `dist` folder to GitHub Pages whenever `main` is pushed.
